# TypeScript Assignment

This repo has my solutions for the TypeScript problem solving assignment. It covers what we learned in Module 1 to 3, like basic types, interfaces, type narrowing, generics, promises and OOP.

## Files

- `solutions.ts` has the solutions for all 8 problems.
- The `.md` files are my blog posts.

Run this to check the code for type errors:

```bash
npx tsc --strict --noEmit --target es2020 solutions.ts
```
